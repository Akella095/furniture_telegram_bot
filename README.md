# 🪑 Мебельный бот для Telegram

Telegram-бот для магазина мебели с каталогом, оформлением заказов, запросами на консультацию и полноценной админ-панелью.

Написан на Python (aiogram 3 + SQLAlchemy async + SQLite).

## 📋 Функционал

### Для покупателей:
- 📁 Просмотр каталога мебели по вложенным категориям
- 🔍 Поиск товаров по названию, описанию и стране
- 📸 Карточки товаров с фотографиями и характеристиками
- ✅ Оформление заказа (имя, телефон, комментарий)
- 📞 Заказ консультации по товару
- ❓ Служба поддержки (вопросы менеджеру)
- 📦 История моих заказов

### Для администраторов:
- 👨‍💼 Полная админ-панель со статистикой
- 📦 Управление товарами (добавление, редактирование, удаление, фото)
- 📁 Управление категориями (вложенность, переименование)
- 📋 Просмотр и фильтрация заказов, смена статусов
- 📞 Управление заявками на консультацию
- ❓ Ответы на вопросы пользователей прямо из бота
- 🔔 Уведомления о новых заказах и вопросах в чат менеджера

## 🚀 Быстрый старт

### Предварительные требования
- Python 3.10 или выше
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

### Установка

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/Vermito/furniture_bot.git
   cd furniture_bot
   ```

2. **Создайте виртуальное окружение и установите зависимости**
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Для Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **Настройте переменные окружения**
   Создайте файл `.env` в корне проекта:
   ```env
   BOT_TOKEN=ваш_токен_от_BotFather
   ADMIN_IDS=ваш_telegram_id
   ```

4. **Запустите бота**
   ```bash
   python bot.py
   ```

## 🐳 Запуск через Docker

Проект полностью подготовлен для запуска в контейнере. База данных сохраняется в папке `data`.

```bash
docker compose up --build -d
```

Остановка:
```bash
docker compose down
```

## 🗄️ База данных

При первом запуске база данных SQLite создаётся автоматически. Бот сам заполнит начальные категории (Спальная, Кухонная, Мягкая мебель и др.) и добавит администраторов из файла `.env`.

## 🛠️ Технологии

- **Python 3.12**
- **aiogram 3** — Telegram Bot API
- **SQLAlchemy 2.0 (async)** — ORM
- **SQLite (aiosqlite)** — база данных
- **Docker** — контейнеризация
