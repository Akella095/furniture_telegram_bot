# 🪑 Мебельный бот для Telegram

Telegram бот для магазина мебели с каталогом, заказами и админ-панелью.

## 📋 Функционал

### Для покупателей:
- 📁 Просмотр каталога мебели по категориям
- 🔍 Поиск товаров
- ✅ Оформление заказов
- 📞 Заказ консультации
- ❓ Поддержка

### Для администраторов:
- 👨‍💼 Полная админ-панель
- 📦 Управление товарами (добавление, редактирование, удаление)
- 📁 Управление категориями
- 📋 Просмотр заказов
- 📞 Управление консультациями
- ❓ Ответы на вопросы пользователей

## 🚀 Быстрый старт

### Предварительные требования
- Python 3.10 или выше
- Telegram Bot Token (получить у @BotFather)
